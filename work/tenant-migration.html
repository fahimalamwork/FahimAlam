1.07 TB moved, zero discrepancies

Migrating public-safety agencies to a new SharePoint tenant, rebuilding their document sync on a cell-based architecture, and the production incidents I traced along the way.

01Context

Tranquility builds TimePilot, an AI platform used by police departments, sheriff's offices, prosecutors and other public-safety agencies. Agencies connect their SharePoint and Google Drive document stores, and the platform keeps them in sync.

The data is CJIS-sensitive, which leaves no room for "mostly migrated". Every file has to arrive, and we have to be able to prove it did.

02The migration

I moved 12 customer tenants to a new SharePoint tenant. Each run followed a runbook and executed rclone jobs on EC2, then reconciled source against destination by exact file count and byte count.

03Keeping it in sync

Moving the data once isn't enough. I set up 12+ SharePoint and Google Drive sync integrations on a new cell-based architecture. On the Microsoft side, Graph change subscriptions notify the platform when something changes, through an Azure Function relay.

04Incidents I traced

Running syncs across many tenants means things break in production. These are the ones I found and fixed.

22 tenants affected

Syncing stopped for 22 tenants

I traced it to an expired SharePoint refresh token and shipped a fix that saves rotated tokens to AWS Secrets Manager.

Every production cell

Sync service wouldn't start

I fixed a startup crash in the sync service and restored syncs fleet-wide.

46 tenants at risk

An apostrophe broke HTTP headers

A tenant name containing an apostrophe broke HTTP headers, which put 46 tenants at risk. I found the bug and got it fixed.

933 objects

Accidental S3 deletion, reversed

I restored 933 deleted S3 objects using bucket versioning.

05Around it

  • Provisioned 25+ agency tenants and offboarded 10+, including S3, KMS and integration cleanup.
  • Wrote the runbooks, plus customer IT setup guides for SharePoint and Google Drive.
  • Run weekly release regression with per-tenant Playwright smoke tests and a Jira Xray onboarding test plan.
